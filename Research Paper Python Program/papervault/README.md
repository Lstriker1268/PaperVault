# PaperVault

## Checklist

- [X] Run `main.py`.
- [X] Choose `1` to add a paper.
- [X] Enter a category and an optional PDF file path.
- [X] Choose `4` to save the library.
- [X] Choose `5` to load the library and open the saved PDF if it exists.

## Notes

- Saved files are stored in the `papers/` folder, grouped by category.
- If a PDF cannot be opened, the category folder will open instead.
- `base_entry.py` is the template for inheritance and interface-style methods.
